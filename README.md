# Fitness Buddy - AI-Powered Fitness & Nutrition Tracker

Fitness Buddy is an intelligent, autonomous agent application built as part of the IBM University Engagement Internship Project. It leverages advanced AI orchestration to deliver personalized health insights, fitness regimes, and real-time nutritional tracking.

## 🚀 Key Features
* *User Dashboard:* A centralized, interactive hub to view overall fitness and health metrics.
* *Workout Tracker Agent:* Generates and logs custom daily exercise charts based on user biometrics.
* *Calorie Calculator Agent:* Seamlessly records food logs and monitors macro targets dynamically.

## 🛠️ Technology Stack
* *Core AI Compute:* IBM Watsonx.ai Cloud Infrastructure
* *Foundation LLM:* IBM Granite (Code & Reasoning Model)
* *Workflow Design:* Langflow Workflow Automation Canvas
* *Frontend UI Stack:* Built using responsive HTML5, CSS3, and native JavaScript (JS).
